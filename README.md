# NekoChunks

Fabric mod cá nhân cho Minecraft **1.21.1** (Java 21, Fabric Loader ≥0.19.5).
Mục tiêu duy nhất: làm việc load/dựng chunk mượt hơn, giảm khựng khi di chuyển nhanh.

## Build

```powershell
.\gradlew.bat build
```

Jar nằm ở `build/libs/nekochunks-1.0.0.jar`.

Chạy client thử nghiệm: `.\gradlew.bat runClient`
